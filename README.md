### Reading Roulette

**Turn “What should I read next?” into a tailored reading idea and a ready-to-use prompt.**

A prompt builder for self-directed language learners who want more reading practice with less time spent choosing. Set a target language, CEFR-tuned level, and reading length. Each spin combines a **Topic × Format × Angle** into a fresh idea, then prepares a prompt for the learner’s preferred AI chat to generate the text.

[**Try the live app →**](https://iaroslav-tkachenko.github.io/reading-roulette/) · [**View source code →**](https://github.com/iaroslav-tkachenko/reading-roulette)
